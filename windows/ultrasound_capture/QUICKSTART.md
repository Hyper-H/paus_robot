# Windows 超声图像接入：快速使用

## 下载和运行

在 [paus_robot Releases](https://github.com/Hyper-H/paus_robot/releases) 中选择
Windows x64 测试版，下载附件 `PausUltrasound-*-windows-x64.zip`。
解压到普通文件夹后双击 `PausUltrasound.exe`；不要直接在压缩包内运行。
无需安装 Visual Studio、C++ 工具链、Python 或 ROS 2。

要求 Windows 10 2004 或更新的 x64 系统，以及正常工作的图形驱动。
厂家软件需另行安装并能够正常显示超声图像。采集器不能替代厂家软件或开启采集卡。

## 首次配置

1. 在 Linux 启动配套的 USFR v2 接收器；窗口采集器和 ROS 接收端的使用说明见
   [源码仓库](https://github.com/Hyper-H/paus_robot)。测试版应配合其 Release 标记对应的源码使用。
2. 打开采集器的“设备设置”，在“来源”选择厂家程序 `.exe`。
   在“接收端”填写 Linux 电脑的局域网 IPv4 地址和监听端口，默认端口为 `55001`。
3. 保存设置，确认厂家窗口已有图像，进入“调整图像区域”。
   框选 B-mode 区域，使用局部放大、边角选择和 1 px 调整检查边界。
4. 检查裁剪预览，勾选选区确认并保存，然后回到主屏点击“开始传输”。
   接收器尚未启动时会等待连接。窗口编辑仅固定本程序的参考帧，不冻结厂家软件。

## 日常使用

- 配置保存于 `%LOCALAPPDATA%\PausUltrasound\profile.json`，下次打开会读取。
  发布包不附带实验室机器的配置；新电脑首次需要配置。
- “尺寸比例”可选。两轴分别记录；只有纵向标尺时，横向保持未知。
  显示标尺估计不等于机器人超声空间标定。
- 默认关闭主窗口后留在托盘，传输可以继续；右键托盘图标可暂停或退出。
  此行为可在“启动行为”中修改。
- 修改选区或窗口尺寸后需要重新确认。厂家同尺寸下的深度、缩放或模式变化
  仍需人工复核；图像中的文字、测量线等覆盖内容不会自动去除。
- 更新程序前先退出旧版本，再解压新版。通常无需删除用户配置文件。
