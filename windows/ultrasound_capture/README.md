# Windows 超声图像接入

`PausUltrasound.exe` 在已登录的 Windows 桌面中运行，使用 Windows Graphics
Capture 读取厂家窗口，裁剪 ROI、转换为 mono8，通过 USFR v2 发给 Linux ROS 2。
它不调用超声硬件 SDK，也不控制机械臂。

## 使用条件

- Windows 10 2004 或更新版本；当前 WGC 路径要求支持关闭系统光标捕获。
- 厂家软件已经安装，操作员可按其正常流程获得 B-mode 图像。
- Windows 能访问 Linux 接收端的 IPv4 地址和 TCP 端口。
- 保持用户桌面登录。最小化厂家窗口会暂停发送；锁屏、显卡切换等仍需按设备验证。

## 第一次使用

1. Linux 启动超声接收器。需要同时查看图像时，可运行现有控制台和接收器：

   ```bash
   bash scripts/start_ultrasound_ui.sh <LINUX_IPV4> 55001 8088
   ```

   该入口关闭相机和手眼标定进程，固定 `execute_motion:=false`。
   浏览器打开 `http://<LINUX_IPV4>:8088`，展开“超声图像”。

2. Windows 双击 `PausUltrasound.exe`，从主屏进入“设备设置”。在“来源”中
   选择厂家 `.exe`，工作目录和进程名会随选择填写；特殊匹配条件放在高级设置。
   工作目录是厂家程序启动时查找资源的目录，不是图像保存目录。成像设置备注
   用于记录探头、深度和缩放等条件，不控制厂家软件。
3. 在“接收端”填写 **Linux 的 IPv4 地址**和端口。按需设置启动行为并保存。
   配置保存与开始传输是两个独立操作。打开厂家软件时，已有进程会被复用；
   否则从配置入口启动一次。采集器不会反复重启厂家程序，也不会开启采集卡。
4. 主屏进入“调整图像区域”。发送先暂停，编辑器固定当前捕获帧供精调；
   这不会操作厂家软件的冻结或电影模式。拖出大致范围后，点选边或角，
   在共用局部放大窗中以 4x/8x 检查内外两侧，用方向按钮或数值输入按原图
   1 px 微调。原图范围外不能继续移动，选中边角本身不会改变 ROI。
5. 右侧裁剪预览显示实际 mono8 输出。检查四边及文字、测量线等叠加物，
   勾选确认并保存区域。需要新画面时使用“更新参考帧”后重新检查。系统
   光标捕获已关闭，但厂家自己绘制的标记不会自动去除。
6. 可选：展开“尺寸比例”，选横向或纵向，在完整参考帧上点两个刻度，
   填写距离与 mm/cm 单位，核对后记录比例，再保存区域。两轴分别记录；
   只有纵向依据时，横向保持未知。该比例不代表探头到机器人坐标的标定。
7. 返回主屏，点击“开始传输”。接收端未启动时会等待并自动重连。
   Linux 页面仅用于观察图像，传输不依赖浏览器是否打开，也不需要运行标定。

## 编辑与保存

- 主屏以裁剪后的图像为主，设备路径、连接地址和启动选项位于设置页。
- 打开设置查看或修改草稿不会立即改变当前传输。保存来源、接收地址或
  成像条件变化时会暂停或重新获取预览；只保存启动和托盘偏好不会打断当前流。
- 修改 ROI 会取消确认，保存区域后保持暂停；再次发送须在主屏明确开始。
- 取消编辑不写入配置。存在未保存修改时，返回或退出会提供保存、放弃修改
  和继续编辑的选择。未通过检查的草稿不能保存。
- “选整个窗口”将输出范围设为厂家完整窗口，包含其 UI；“恢复已保存选区”
  恢复原配置的裁剪范围，两者不同。放大窗的遮罩和边界线只用于查看，不进入输出。
- 边界与标尺共用放大窗。记录新标尺时保存完整取点位置；旧配置若只记录了
  单轴坐标，其比例仍能读取，缺失的定位信息须重新取点，不会自动猜测。

## 日常使用

- 配置保存到 `%LOCALAPPDATA%\PausUltrasound\profile.json`。下次打开自动
  载入，并按启动选项打开/复用厂家软件。勾选并保存“启动时自动传输”后，参考尺寸、DPI 和
  ROI 确认均匹配时才会自动连接；否则需要重新确认。
- 默认关闭主窗口会收起到托盘，继续采集/传输；此偏好可在设置中修改。
  托盘可恢复窗口、暂停传输或退出。
- 暂停只停止发送，仍可预览；退出只关闭本程序，不终止厂家软件。
- 应用 ROI、源程序或成像条件变化会暂停传输并使相应确认失效。窗口尺寸/DPI
  变化时需重新确认；编辑参考帧与当前窗口不匹配时不能保存为有效区域。
  软件无法可靠自动识别同尺寸下的深度、缩放、模式变化，操作员必须更新
  成像条件并复核 ROI 和标尺比例。
- ROI 裁剪不缩放像素；比例针对捕获帧像素。裁剪会平移图像原点，不能把
  ROI 左上角当成探头物理原点。未知尺度为 `null`，`geometry_valid` 保持 false。
- 损坏的配置文件会报错并保留原文件，不能静默覆盖。备份后可移到其他名称
  再重新配置。

## 状态与指标

`WAIT_WINDOW` 等待厂家窗口；`PREVIEW` 只预览；`NEEDS_ROI` 配置与当前画面
不匹配；`CONNECTING` 等待 Linux；`STREAMING` 持续收到 ACK；`STALE` 没有近期
捕获帧。ACK 表示接收器接收并校验完成，不表示分割或机器人已使用该帧。

采集器仅保留最新帧，同时最多发送一帧，发送及 ACK 共用截止时间；连接中断
后退避重连，不会无限排队。窗口捕获时间和 Linux 收帧时间分别属于不同机器，
ACK 耗时与帧年龄均不等于严格声学采集到 ROS 的延迟。

## 构建与分发

开发机需要 Visual Studio 2022 C++ Build Tools、CMake 及包含 C++/WinRT 的
Windows SDK。建议使用已验证的 10.0.26100.0 SDK。执行：

```bat
build.cmd
```

脚本使用 `C:\BuildTools` 或当前 Visual Studio 开发者命令行环境，构建
Release、运行核心和配置持久化测试，然后输出 `dist\PausUltrasound.exe`。
Release 静态链接 C++ 运行库；接收设备只需拷贝 exe，不需要安装开发工具链。
图标已编入程序，运行时无需浏览器或外部图片；分发时附带 `dist\licenses` 中
的 Lucide 许可。

Linux 可以验证跨平台图像/配置核心：

```bash
cmake -S windows/ultrasound_capture -B /tmp/paus-capture-core
cmake --build /tmp/paus-capture-core
ctest --test-dir /tmp/paus-capture-core --output-on-failure
```

## 后续扩展

标尺识别可增加独立标尺 ROI，检测刻度并 OCR 数字/单位，生成候选比例后由用户
确认。低置信度、单位缺失、非线性扇形坐标或间隔不一致时保留未知值，不直接
变成有效几何。当前版本只实现人工取点，不包含 OCR、自动边界吸附或分割模型。
