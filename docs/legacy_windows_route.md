# Legacy Windows 路线

仓库仍然保留旧的 Windows / WSL 双桥方案，位置在：

- `legacy/hybrid_stack/`
- `legacy/windows_bridge/`
- `legacy/vendor/`

这些内容现在只作历史回溯和参考，不再作为默认主线。

## 归档内容
- Windows 相机桥
- Windows FAIRINO 执行桥
- 旧的 ROS2 vendor 包

## 当前推荐
默认使用 Linux 原生主线：
- `paus_perception`
- `paus_marker_ros2`
- `paus_motion_ros2`
- `paus_bringup`
